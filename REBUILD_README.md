# PayComp Website Rebuild Sandbox

This branch is an isolated, editable rebuild of the public-facing PayComp website. It is intentionally separate from the existing Resource Hub on `main`.

## Branch
`website-rebuild`

## Files
- `index.html` — homepage markup and copy
- `styles.css` — all layout, color, responsive and animation styling
- `script.js` — mobile navigation and scroll-reveal behavior
- `paycomp-logo-top.png` — existing PayComp logo asset inherited from the repository

## Editing
This version uses plain HTML, CSS and JavaScript so changes can be made directly in GitHub without a build pipeline.

## Local preview
Open `index.html` in a browser, or serve the directory with any static web server.

## Important
The live production site is not modified by this branch. When the rebuild is ready, the development team can port the approved markup/styles into the production framework or merge selected work through a normal review process.
